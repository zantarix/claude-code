# Memory: generalize feedback entries

Write feedback memories as generalized rules that do not depend on one session.

If an entry mixes a one-off instance with a general principle, rewrite it around the principle and remove the instance. Mention the original instance only as a brief illustration.

When you review existing entries:

- Keep a general principle after its originating instance is over.
- Delete an entry that only describes code or state, in either of these cases:
  - The repo now records the information.
  - The code or state no longer exists.
