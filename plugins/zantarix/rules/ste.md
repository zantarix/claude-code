# Simplified Technical English

Use Simplified Technical English in messages to the user and in any documentation you write. Apply it strongly to other writing tasks unless told otherwise.

When a fixed format conflicts with these limits, keep the format's structure. Headings, fields, table columns, and trailers stay as the format defines them. Apply these rules to the prose you write inside them.

## Definition

**Word choice**

- Give each word one meaning. Do not rely on context to select one of several dictionary senses.
- Use the meanings in the project's `CONTEXT.md` or `CONTEXT-MAP.md` where they apply.
- Choose the plainer, shorter, more common word over a formal or rare synonym.
- Use the verb for an action, not a noun made from it. Write "inspect", not "carry out an inspection".
- Do not use phrasal verbs. A phrasal verb is a verb plus a particle, with a meaning that differs from its parts. Write "configure", not "set up". Write "discover", not "find out".

**Verb forms**

- Use these forms: infinitive, imperative, simple present, simple past, and simple future.
- Use a past participle only as an adjective or in a permitted passive (see Voice).
- Do not use perfect tenses. Write "We received", not "We have received".
- Do not use progressive tenses. Use an "-ing" word only as a technical noun or as part of one.
- Use the auxiliaries "will", "can", "must", and "do" when needed.

**Voice**

- Use the active voice in procedures and instructions.
- Use the passive voice only in descriptive text, and only when the actor is unknown or irrelevant to the reader.

**Sentence structure**

- Write one instruction in each sentence.
- Use 20 words or fewer in a sentence for procedures and instructions. Use 25 words or fewer in descriptive text.
- Do not drop the verb, subject, or article to shorten a sentence.
- Limit a noun cluster (nouns stacked as a modifier) to 3 words.
- Do not use semicolons. Write separate sentences. Use any other standard punctuation, including the em dash.

**Paragraph and document structure**

- Write one topic in each paragraph.
- Use 6 sentences or fewer in a paragraph.
- Use a vertical list (numbered or bulleted) for sequences, conditions, and lists of more than three items. Do not bury them in prose.
- Use the Oxford comma in inline lists, for both "and" lists and "or" lists.

**Safety instructions**

- Start an instruction with its command or condition when a mistake would lose data, cannot be undone, or exposes secrets. Examples are force-push, delete, drop, and overwrite. Do not put it in the middle of a sentence.
