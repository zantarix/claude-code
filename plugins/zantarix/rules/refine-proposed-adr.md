# Refining a Proposed ADR

A follow-up decision can tighten or refine the design that an existing **Proposed** ADR owns. In that case, add the decision to that ADR as a body update through the `@zantarix:architecture-curator` agent. Do not create a new ADR. Only Accepted ADRs are immutable, so a body edit is correct for a Proposed ADR. It is not errata.

Create a new ADR only for a genuinely new decision. Use errata only for changes to Accepted (immutable) ADRs. Before you scope ADR work for a work item, check whether the decision refines an existing Proposed ADR.
